# ШУТИС ус цэвэршүүлэгчийн үйлчилгээний бүртгэл

ШУТИС-ийн ус цэвэршүүлэгч төхөөрөмжүүдийн бүртгэл, шүүлтүүр солих хугацаа, үйлчилгээний товлолт болон солилтын түүхийг удирдах хичээлийн demo систем.

## Боломжууд

- Төхөөрөмж, суурилуулсан огноо, солих давтамж, байршил болон хариуцах компанийг бүртгэх
- Солих хугацаа 7 хоног дутуу үед мэдэгдлийн жагсаалтад харуулах
- Компаниар шүүж, үйлчилгээний өдөр товлох
- Шүүлтүүр сольсныг тэмдэглэж, дараагийн солих хугацааг тооцоолох
- Үйлчилгээний түүх болон feedback-ийг SQLite өгөгдлийн санд хадгалах
- Цайвар болон бараан хөх theme сонгож хадгалах

Борлуулалт, төлбөр тооцоо болон бодит хэрэглэгчийн нэвтрэлт энэ demo-д ороогүй. Компанийн сонголт нь компанийн ажлыг харах demo шүүлтүүр юм.

## Ажиллуулах

Шаардлага: .NET 10 SDK.

```powershell
dotnet run --urls http://localhost:5089
```

Дараа нь `http://localhost:5089` хаягийг браузераар нээнэ. SQLite өгөгдлийн сан анх ажиллахад `App_Data/watercare.db` замд үүсэж, жишээ төхөөрөмжүүд автоматаар бүртгэгдэнэ.

## API

- `GET /api/dashboard?company=...`
- `GET /api/filters?search=...&company=...`
- `POST /api/filters`
- `POST /api/filters/{id}/schedule`
- `POST /api/filters/{id}/replace`
- `GET /api/history?company=...`
- `GET /api/feedback`
- `POST /api/feedback`
